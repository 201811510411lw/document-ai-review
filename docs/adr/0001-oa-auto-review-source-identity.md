# OA auto review is scoped by OA request identity

An OA source request is identified by `workflow_id + requestid`, while each review submission is identified and made idempotent by `workflow_id + requestid + submission_version`. `submission_version` is a positive integer starting at `1`. OA increments it only when an applicant resubmits after a return; retries of the same submission keep the same version. Version `1` retains the legacy task ID `tc-oa-{workflow_id}-{requestid}`, while later versions use `tc-oa-{workflow_id}-{requestid}-s{submission_version}`. Each version creates a separate Review Task and reloads evidence from the exact OA request; the source adapter must never infer the request from a store name, title, or latest record. Request-provided callback URLs are not trusted source configuration; outbound result delivery uses only the server-managed callback URL.
